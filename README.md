# MarqueeJay — Movie Booking UI

A frontend-only movie discovery and booking experience inspired by modern cinema-booking platforms. Built with HTML, CSS, and vanilla JavaScript.

## Features
- Movie discovery cards
- Search and genre filters
- City selector
- Movie details modal
- Date and showtime selection
- Interactive seat selection
- Booking summary and confirmation
- Responsive mobile-first layout
- Local storage for selected city

> This is an original educational project and is not affiliated with or a copy of any specific commercial service.
